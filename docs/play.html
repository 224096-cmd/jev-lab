🗂 OSINT Framework ツール集（対象を入れるとリンクが全部できる）

カテゴリごとに「自動（このアプリが API で実行）／端末内／リンク（対象を埋め込んだ URL）」を並べる。人物検索・出会い系・ダークウェブ・テロ・クラシファイドは扱わない。

🖼 画像：EXIF / GPS・ELA（改ざん痕）・逆画像検索

自分の端末の画像を端末内で読む。SNS 経由の画像は通常 EXIF が消えている＝残っていれば一次投稿の可能性。ELA は再圧縮の差分で編集領域を浮かび上がらせる（FotoForensics と同じ原理、断定はしない）。

📄 文書メタデータ（PDF / Word / Excel / PowerPoint）

FOCA / Metagoofil 相当。作成者・最終更新者・作成ソフト・編集時間を端末内で読む。公開前の自分の文書の点検にも。

🧪 ファイルのハッシュ → VirusTotal / MalwareBazaar で検索

ファイルは送信しない。端末内で SHA-256 を計算し、そのハッシュで公開データベースを検索する（既知のファイルなら結果が見られる）。証拠ファイルの同一性確認にも。

☎️ 電話番号の書式・種別（端末内）

携帯 / IP 電話（050）/ フリーダイヤル / 固定（市外局番）を判定。持ち主の特定はしない。

🛡 OpSec：ブラウザの露出情報／パスワード漏えい確認

「調べる側」が特定されないための自己点検。何も送信しない（パスワードは SHA-1 の先頭 5 文字だけを送る k-匿名性方式）。

JEV の役割：届いた文章をその場で・端末内で「種類／緊急度／具体性／拡散依頼／根拠との整合」に仕分け、要確認だけを残す。生成しないので誤情報を作らず、確率が出るので「自動採用／人手確認／除外」のしきい値運用ができる。認証情報はこの端末の中にだけ保存し、各サービス以外には送らない。

📲 共有メニューから受け取る

Android：このサイトを「ホーム画面に追加」すると、X・LINE・ブラウザなどの共有に「JEV Lab」が出る。共有した文章がそのまま「判断」に入る。

iPhone：「ショートカット」アプリ → 新規 → 「共有シートに表示」をオン → アクション「URL を開く」に を入れ、末尾に「ショートカットの入力」を挿入。共有シートから呼べる。

PC のブラウザ：下のブックマークレットをブックマークバーへドラッグ（またはブックマークの URL に貼る）。ページで文章を選択してクリックすると JEV に送られる。

「文章を判断」に入れた文章・根拠・質問を使い、何を変えると出力がどう変わるかを測る。各項目に「良い結果」の目安を書いた。

① 根拠あり／なし

根拠（context）を外すと答えや分布がどれだけ動くか。動けば根拠を参照している。L1 = 確率ベクトルの差の絶対値の和（0〜2）。

② 選択肢の順序シャッフル

順序を変えても同じ答えなら位置バイアスが小さい（一致率 100% が理想）。

③ Noul の否定形

質問を否定形にすると p(yes) が反転するか。反転しなければ質問文を読まず状況だけで答えている。

④ 選択肢を 1 つ抜く

最尤の選択肢を抜いたとき、次に妥当な選択肢に移るか（分布の一貫性）。

⑤ モデル × 手法 マトリクス

同じ入力を複数モデルで。JEV-JA は head/cos × span/marker、HF モデルは 1 行。

⑥ 推論時間

同じ入力を繰り返し、p50/p95 を測る（Fast 軸）。

回

gold 付き JSONL を端末内で評価し、精度・Brier・ECE・速度を実験ノートに記録する。95% 信頼区間（ブートストラップ）と多数決・ランダムのベースラインを並べて表示。

JEV-JA の判断ヘッドを、この端末で再学習する

エンコーダは固定し、判断ヘッド（MLP 約 40 万パラメータ）だけを JS で学習する。数百件なら数十秒。学習前後を同じ検証データで比べ、良ければ保存（以後この端末の JEV-JA はそのヘッドを使う）。PC の学習（train_jev_ja.py）はエンコーダごと更新する本格版。
