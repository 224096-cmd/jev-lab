モデル （端末内で動く Jev 級のみ）

モデルを変えると変わる場所：調べる（1 件ごとの種類・信頼性）／見極める（判定・危険度）／仕分ける（経路）／聞く（答え）。同じ入力をもう一度実行すると「モデルによる違い」が並びます。スマホは 100 MB 以下（jev_ja_30m・jevlet_33m・openjev_base_60m）を推奨。

集める・見極める・仕分ける・聞く

公開情報を集めて、端末内の判断モデル（Jev 級）が 1 件ずつ「種類・具体性・拡散依頼・根拠との整合」を確率つきで答える。生成しないので嘘を作らず、確信度で「自動／人が確認」に分けられる。

文章は「見極める」で判定します。

収集の設定

見極める — 投稿・メール・主張を 1 回で多面的に判定

根拠（context）を足す

公的発表・報道・地理情報など「確かな情報」を 1 行 1 つ。入れると「根拠と整合しているか」「主張と根拠の関係」を判定する。

質問を自分で決める（上級）

プリセットの質問を編集・追加できる。JSON でも編集可。

主張と根拠を照合

主張（上の文章）に対して、根拠の各行が「支持／矛盾／無関係」のどれかを判定（citation check）。

同じものか判定

2 つの記述（アカウント・団体・出来事）が同一かを判定（entity alignment）。名寄せ・重複投稿の確認に。

別モデルで照合

同じ文章を別のモデルにも問い、答えの一致を見る（一致＝より確か）。

仕分ける — 何十件でも同じ問いで、確信度つきで経路を決める

根拠（context）・並び順

文書 — 問う相手

聞く — はい/いいえ・選択・段階・どの行

書き方：? 質問＝はい/いいえ　質問 | A | B＝選択　度合い: 質問＝0〜5　どの行: 内容＝該当する行を指す（該当なし可）。生成はしない。

検索式の自動生成、OSINT Framework のツール集（対象を入れるとリンクが全部できる）、端末内で動く解析ツール。ファイルは送信しない。

🗂 OSINT Framework ツール集（対象を入れるとリンクが全部できる）

カテゴリごとに「自動（このアプリが API で実行）／端末内／リンク（対象を埋め込んだ URL）」を並べる。人物検索・出会い系・ダークウェブ・テロ・クラシファイドは扱わない。

🖼 画像：EXIF / GPS・ELA（改ざん痕）・逆画像検索

自分の端末の画像を端末内で読む。SNS 経由の画像は通常 EXIF が消えている＝残っていれば一次投稿の可能性。ELA は再圧縮の差分で編集領域を浮かび上がらせる（FotoForensics と同じ原理、断定はしない）。

📄 文書メタデータ（PDF / Word / Excel / PowerPoint）

FOCA / Metagoofil 相当。作成者・最終更新者・作成ソフト・編集時間を端末内で読む。公開前の自分の文書の点検にも。

🔣 変換（CyberChef 相当）・文字列の種類判定

🧪 ファイルのハッシュ → VirusTotal / MalwareBazaar で検索

ファイルは送信しない。端末内で SHA-256 を計算し、そのハッシュで公開データベースを検索する（既知のファイルなら結果が見られる）。証拠ファイルの同一性確認にも。

☎️ 電話番号の書式・種別（端末内）

携帯 / IP 電話（050）/ フリーダイヤル / 固定（市外局番）を判定。持ち主の特定はしない。

🛡 OpSec：ブラウザの露出情報／パスワード漏えい確認

「調べる側」が特定されないための自己点検。何も送信しない（パスワードは SHA-1 の先頭 5 文字だけを送る k-匿名性方式）。

📚 学ぶ・証拠保全・関連ツール

この端末の実験記録（IndexedDB）。卒論の表は「卒論用の表」か CSV から。

JEV の役割：届いた文章をその場で・端末内で「種類／緊急度／具体性／拡散依頼／根拠との整合」に仕分け、要確認だけを残す。生成しないので誤情報を作らず、確率が出るので「自動採用／人手確認／除外」のしきい値運用ができる。認証情報はこの端末の中にだけ保存し、各サービス以外には送らない。

👁 監視（定点観測）

一定間隔で取り込み直し、新しく「要確認」になった投稿だけを通知する（ブラウザ通知）。タブを開いたままにする。

📲 共有メニューから受け取る

Android：このサイトを「ホーム画面に追加」すると、X・LINE・ブラウザなどの共有に「JEV Lab」が出る。共有した文章がそのまま「判断」に入る。

iPhone：「ショートカット」アプリ → 新規 → 「共有シートに表示」をオン → アクション「URL を開く」に を入れ、末尾に「ショートカットの入力」を挿入。共有シートから呼べる。

PC のブラウザ：下のブックマークレットをブックマークバーへドラッグ（またはブックマークの URL に貼る）。ページで文章を選択してクリックすると JEV に送られる。

① 根拠あり／なし

根拠（context）を外すと答えや分布がどれだけ動くか。動けば根拠を参照している。L1 = 確率ベクトルの差の絶対値の和（0〜2）。

使えるモデル

すべて Jev 級（state + 型付き質問 → 1 forward で較正済み分布、生成しない）。スマホは jev_ja_30m（47 MB）、PC ブラウザなら Laya / argos（約 320 MB）も。

Hugging Face で Jev 級モデルを探す

HF API（公開）。最終更新順。transformers.js / onnx タグがあるものはブラウザ実行の候補。それ以外は PC（config/models.yaml）用。

モデルを追加（コピペ）

対応する kind：open-jev-onnx（open-jev 形の Transformers.js 版。HF から直接）、crossenc（日本語 Jev cross-encoder。PC で export_crossenc.py）、laya（Laya 系。PC で export_laya.py）。crossenc / laya は docs/models/ に置いて push すると index.json に自動登録される。Jev 級でないモデル（NLI・埋め込み・LLM）は比較対象にしない。
