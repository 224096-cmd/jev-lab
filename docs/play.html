JSONL（1 行 = 1 state、bench/data/*.jsonl と同じ形式）を端末内で評価し、精度・Brier・ECE・p50/p95 を出す。結果 JSON は docs/results/ に置く形式と同じ。

評価結果は自動で「実験ノート」に記録される（モデル・手法・pool・T・データ・端末・時刻つき）。

利用方針：運営者が公開 API として提供しログイン不要で CORS を許可している情報源だけを使う。対象は出来事・地域・話題。個人の特定・追跡・プロファイリングには使わない。取得結果は出典 URL と取得時刻つきで記録する（証跡）。レート制限（Nominatim 1 req/s、GDELT 5 s/req）を守る。

score = Σ wk·fk / Σ wk。f: 公的発表(0/1)、根拠と整合 p、具体性 p、種類（公的1／報道0.8／目撃0.5／意見0.2／無関係0）、拡散依頼なし 1−p、関連 p。JEV の出力をルールで合成する「説明できるスコア」。

この端末で行った実験の記録（IndexedDB）。卒論の表はここから CSV で出す。PC で回した結果（docs/results/）は「解説・結果」ページに統合表示される。
