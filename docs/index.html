JEV Lab

概要・結果情報収集・判断仕組み

小さな判断モデル（Jev 級）で、公開情報を集めて・仕分けて・根拠と照らす。

生成しない。1 回の forward で「関連・種類・緊急度・具体性・拡散依頼・根拠との整合」を確率つきで返す 30〜70M パラメータのモデルを日本語で構築し、スマホのブラウザ内（オフライン可）で動かす。収集は公開 API のみ、判断は説明できる形で、証跡を残す。

できることどこで
ドメイン・IP・メール・座標・暗号資産アドレス・CVE などを入れると種類を自動判定し、公開 API を横断して集め、JEV が「正規か／なりすましの疑い」を判定。OSINT Framework の合法な範囲をリンク集として内蔵Play「調査」
調べたいことを入れて公開情報を収集 → JEV が種類・緊急度・具体性・拡散依頼・根拠との整合を判定 → 要約と要確認リスト → 信頼性順 → 証跡保存。保存した検索の新着確認Play「情報収集」
1 件の文章に Choice / Score / Noul の質問を当てて答えカードで見る。複数テキストの一括判断と集計。チャットで「? 返信が必要か」と問い直すPlay「文章を判断」「一括判断」「JEV チャット」
根拠あり/なし・順序・否定形・選択肢除去・モデル×手法マトリクス・時間計測Play「検証」
入力列・ベクトル・logit・PCA を可視化、数式つき解説Play「仕組み・可視化」／仕組みページ
10 family の JevBench-JA や自分の JSONL を端末内で評価（95% CI・ベースライン付き）、実験ノートに記録、卒論用の表を出力Play「バッチ評価」「実験ノート」
学習・ONNX 化・大型モデル比較（GLiNER2 / open-jev / NLI / LLM）PC（VS Code）

リーダーボード（PC の結果 docs/results/ を統合）

JevBench 流に 5 軸を並べ、合成スコアは作らない。native = モデル自身の分布、verbalized = LLM が書いた分布。端末での結果は Play の実験ノートから CSV で出す。

docs/results/index.json がありません（PC で python -m jev_lab.bench.run ... --publish）
