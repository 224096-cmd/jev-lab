Jev 級（型付き判断）モデルを日本語で構築・比較する研究環境。学習と大型モデルとの比較は PC（VS Code）で行い、結果とスマホで動く JEV-JA をこのページで公開する。

ベンチ結果（PC で実行 → results/ に保存）

results/index.json がありません（python -m jev_lab.bench.run ... --publish で生成）

1. Jev 級モデルの形

1 つの状況 s に N 個の型付き質問を載せ、1 回の forward で質問ごとの較正済み確率分布を返す。生成しないので構造化出力エラーは構造的に 0。

  • Choice: options 上の分布 → argmax
  • Score: 順序段階上の分布 → 期待値（段階の間に落ちることがある）
  • Noul: {yes, no} 上の分布 → p(yes)

2. JEV-JA の読み出しヘッド

option のテキストトークンの平均を読む（span pool）。新設マーカートークンの hidden state を読む方式（marker pool）は事前学習の構造を持たないため学習しにくいことが英語で報告されている。config/models.yaml の pool を切り替えて日本語で再検証する。

3. 損失と較正

温度 T は検証データで NLL 最小化により事後推定。指標は精度・Brier・ECE（top-label 信頼度を 10 等幅ビンで集計。空ビンは除外し補間しない）。

4. native と verbalized

native モデル自身の分布（エンコーダ系・JEV-JA）。verbalized LLM に確率を書かせたもの。別物として扱い、較正の主張を混ぜない。

5. 端末内実行

JEV-JA はエンコーダを ONNX（int8 動的量子化）に、ヘッドを ONNX に書き出し、ブラウザの ONNX Runtime Web（WASM、対応端末では WebGPU）で実行する。トークナイズは Transformers.js が同梱の tokenizer.json を読む。Python 側と同じ手順（[CLS][STATE] s [Q] instr [OPT] o …）で入力列を作り、スパン平均を JS で計算する。
